# woodson42 journal

A retro-minimal personal journal built with Pelican, Vue Vapor, and Vite.

## Local development

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
pnpm install
pnpm dev
```

Pelican serves the site at `http://localhost:8000`. Vite serves the Vue Vapor modules with hot updates on port `5173`, while Pelican watches content and templates. Production builds still use Vite's generated manifest.

The project commands resolve `.venv` directly, so activating it is optional after the dependencies are installed.

## Production build

```bash
pnpm install --frozen-lockfile
source .venv/bin/activate
python -m pip install -r requirements.txt
pnpm build
```

The complete static site is written to `output/`.

## Project shape

- `content/` contains Markdown articles and pages.
- `theme/templates/` contains Pelican/Jinja templates.
- `frontend/` contains the Vue Vapor interaction layer and the complete visual system.
- `theme/static/dist/` is generated by Vite and resolved through its build manifest.
- `tests/` verifies the integrated Vue and Pelican build.
